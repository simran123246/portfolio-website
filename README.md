# portfolio-website
Company Website

A modern and responsive company website developed using HTML, CSS, and JavaScript. The website is designed to provide a professional online presence with an intuitive user interface, smooth navigation, and mobile-friendly layouts.

Features
- Responsive design for desktop, tablet, and mobile devices
- Modern and clean user interface
- Interactive elements using JavaScript
- Fast-loading and optimized structure
- Well-organized and maintainable code

Technologies Used
- HTML5
- CSS3
- JavaScript

Purpose
This project showcases front-end web development basic skills and demonstrates how to build a professional company website using core web technologies.
